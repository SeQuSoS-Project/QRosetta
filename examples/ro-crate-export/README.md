# Example RO-Crate export

This directory is a real QRosetta export, generated by actually running a circuit through the
full local simulator fleet and calling `POST /export`, not hand-written. It conforms to
[RO-Crate 1.1](https://www.researchobject.org/ro-crate/1.1/) and the
[Process Run Crate profile](https://w3id.org/ro/wfrun/process/0.5), verified with the
[`rocrate-validator`](https://github.com/crs4/rocrate-validator) tool (PyPI package
`roc-validator`):

```
rocrate-validator validate -p process-run-crate examples/ro-crate-export
```

which reports **42/42 REQUIRED checks passed**.

## How this crate was generated

- Circuit: a 5-qubit GHZ state, generated via `POST /generate_circuit` with
  `{"algorithm": "ghz", "qubits": 5}` (see `circuit.qasm`).
- Run: `POST /compare_measured` with `n_shots=4096`, `optimization_level=1`,
  `seed=20260728`, `execution_target=local`, against every enabled backend (14 at the
  time of this export: qiskit, cirq, qulacs, qsim-cirq, qibo, qrisp, myqlm, quimb,
  cuquantum, quest, pennylane-lightning, pennylane-default, pyquil, torchquantum).
- Export: `POST /export` with `include_statevectors=false` and publication artifacts
  for the `agreement` and `statistical` categories, figures in SVG and tables in CSV
  (kept small deliberately; PNG/PDF/LaTeX/XLSX and the other artifact categories are
  also available through the same endpoint on a live run).
- Repository state: git commit `b8a2bb18e7d0bafeb5c08397af1f3cfd301c0edf`.

All 14 backends completed successfully. Of the 91 backend pairs compared, 78 agreed within
the configured JS/Hellinger thresholds and 13 exceeded them (see `tables/agreement.csv` and
`results.json`'s `divergence_report` for the full per-pair breakdown, including which
registered transform, if any, explained each pair).

## Contents

| Path | Description |
|---|---|
| `ro-crate-metadata.json` | The RO-Crate 1.1 / Process Run Crate JSON-LD descriptor. |
| `circuit.qasm` | The input OpenQASM 2.0 circuit. |
| `transpiled_circuits/*.qasm` | The exact circuit each backend executed, after its own preprocessing pass. |
| `results.json` | The full analysis report: per-backend raw results, divergence matrices, pairwise agreement records, performance and resource reports. |
| `provenance.json` | Runner configurations, executed SDK versions, and platform metadata. |
| `figures/*.svg` | Publication-ready figures (agreement distribution, per-pair count histograms). |
| `tables/*.csv` | Publication-ready tables (agreement classification, shot-noise statistical test). |

Reproducing this export from a running local stack only needs the three requests above;
the same export is also reachable from the Exports tab of the running app for any report
you generate there.
