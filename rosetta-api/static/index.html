    Circuit Preprocessing

    Apply SDK Preprocessing On: the API merges quantum registers and round-trips the circuit through pytket, and each backend applies its own passes. Every change is listed per backend. Details
    Local servers only: skips the size and statement-count limits. Qubit limits still apply.

    Compile-only services

    Each ticked level compiles the run's circuit after the simulators finish; outputs are in the Circuits tab and are not simulated or compared. Hover a level for what it runs. With none ticked, no compile-only service runs; with Statevector and Measured both unticked, only these run.

    Agreement Thresholds

    A statevector pair agrees when fidelity ≥ 1 − fidelity tolerance; a phase within the phase tolerance counts as 0. The JS and Hellinger cut-offs are descriptive; the shot-noise test decides measured agreement. Details
