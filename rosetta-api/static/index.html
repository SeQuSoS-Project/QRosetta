    Compile-only services

    Each ticked level compiles the run's circuit after the simulators finish; outputs are in the Circuits tab and are not simulated or compared. With none ticked, no compile-only service runs; with Statevector and Measured both unticked, only these run. Hover a level for what it runs.

    Agreement Thresholds

    Details

    A statevector pair agrees when fidelity ≥ 1 − fidelity tolerance; a phase within the phase tolerance counts as 0. The JS and Hellinger cut-offs are descriptive; the shot-noise test decides measured agreement.
